# Book Tracker

Автор: Шакирова Алия Ренатовна

## Описание
Программа для учета прочитанных книг. Позволяет добавлять книги, фильтровать по жанру и количеству страниц, сохранять и загружать список из файла.

## Требования
- Python 3.x
- Стандартные библиотеки (tkinter, json, os)

## Инструкция по запуску
